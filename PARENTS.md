# Everleigh's Rocky Top Reef — grown-up page

## First open on a device

A short note explains that Chrome may send audio to Google so speech can be understood. A misheard try never counts. Tap always works. The grown-up creates a parent code on this device, enters it again to confirm, and taps Accept. That turns spoken answers on. Parents Corner can turn the mic off later.

## Parent code

Choose the code on first launch. This browser stores only a hash of it, not the digits, and does not send that hash online. Later visits to Parents Corner ask for the code and compare it with the hash on this device. Change parent code asks for the current code, then a new one twice. If this device has no hash yet, the create-code screen is required.

## What the child sees

Check-ins celebrate finishing. Practice gives more pearls when a tap lands, plus a smaller bonus for finishing. Percents, bands, and placement stay on the grown-up page.

## Name on this device

The title is Everleigh's Rocky Top Reef on every screen. There is no nickname field.

## Move my progress

Each browser is separate until you restore a backup. Make a backup code or download the JSON file in Parents Corner, then paste or open it on the other device. There is no account.

## Delete all data

Clear reef memory on this device erases progress and the unlock flag here only.

## Later

A Google login for the grown-up only (progress only, and delete-all) can be added after Firebase is set up. It is not on.
