# Baked voice clips

Read-aloud plays mp3 files in this folder only. If a file is missing, the caption stays on screen and the missing id is logged. Nothing is spoken by the browser voice.

Spoken answers use the microphone only while the mic button is on. The browser asks the first time it is used. Tap answers always work.

Do not call ElevenLabs from the client.

Mom lines are `mom-praise.mp3` and `mom-welcome.mp3`. Sunny clips already baked with Candy stay. The full bake list is `tutor/voice-cast.json`.
